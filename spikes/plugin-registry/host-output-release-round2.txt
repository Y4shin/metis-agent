== what the registry costs
BENCH schema compile: 14 us per schema (14 routed capabilities => 28 schemas compiled at load, about 0.4 ms)
BENCH request validation: 128 ns per call (small object, 1 string field)
BENCH response validation: 191 ns per call (small object, 2 fields)
BENCH both directions: 319 ns per call, the number the registry adds to every routed call
BENCH baseline: serde JSON encode plus parse of the same payload, 127 ns, which validation sits on top of
BENCH registry.invoke end to end, native in process plugin, both directions validated: 486 ns per call
BENCH async completion latency, cdylib through the C table and the landed HostAdapter: 25853 ns per call (25.9 us), one worker thread round trip
BENCH validation share: 66% of the native call, 1% of the cdylib call
BENCH concurrency: 8 threads x 200 calls = 1600 in-flight completions, all matched to their caller, 8892 ns per call wall clock, 14.2ms total
