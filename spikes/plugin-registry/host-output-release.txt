== what validation costs
BENCH schema compile: 4 us per schema (7 routed capabilities => 14 schemas compiled at load, about 0.1 ms)
BENCH request validation: 158 ns per call (small object, 1 string field)
BENCH response validation: 245 ns per call (small object, 2 fields)
BENCH both directions: 403 ns per call, the number the registry adds to every routed call
BENCH baseline: serde JSON encode plus parse of the same payload, 207 ns, which validation sits on top of
BENCH registry.invoke end to end, native in process plugin, both directions validated: 649 ns per call
BENCH registry.invoke end to end, cdylib through the C table, both directions validated: 930 ns per call
BENCH validation share: 62% of the native call, 43% of the cdylib call
